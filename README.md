# Cours animés

Mes cours d'informatique sous forme de pages HTML animées : une page par notion, avec le cours pas à pas, le monde réel et la fiche de révision. Fil rouge : une version simplifiée d'Instagram.

Ce dépôt ne contient que mes propres explications, jamais les supports de mon école. Instagram sert d'exemple d'étude ; ce projet n'y est pas lié.
